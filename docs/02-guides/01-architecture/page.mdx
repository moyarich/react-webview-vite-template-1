# Architecture

A VS Code extension with a webview runs code in two different environments.

## Extension host

The extension host runs in Node.js.

Entry point:

```text
src/extension.ts
```

It can use the VS Code API:

```ts
import * as vscode from "vscode";

vscode.window.showInformationMessage("Hello");
```

It does not have a browser DOM.

## Webview

The webview runs in an isolated browser context.

Source:

```text
src/webview/*
```

It can use React, browser APIs, and the DOM.

It cannot import and use the `vscode` module directly.

## The boundary

The two runtimes communicate with messages:

```text
React webview
    │
    │ vscode.postMessage(...)
    ▼
Extension host
    │
    │ VS Code API
    │
    │ panel.webview.postMessage(...)
    ▼
React webview
```

This separation is the most important concept in the project.

## Source layout

```text
src/
├── extension.ts
└── webview/
    ├── App.tsx
    ├── index.tsx
    ├── index.css
    ├── vscode.d.ts
    ├── api/
    │   └── vscode-api.ts
    └── components/
        └── vscode-ui.tsx
```

## Build layout

```text
dist/
├── extension.js
└── webview/
    ├── webview.js
    └── webview.css
```

Keeping both outputs under `dist/` makes packaging and webview resource paths easy to reason about.


## Command surface

The extension contributes one command:

```text
react-webview-vite.openPanel
```

It is available from the Command Palette, from the editor context menu, and from the Explorer file context menu:

```text
React Webview
└── Open React Webview
```

The submenu is declared with `contributes.submenus` and inserted into `editor/context` through `contributes.menus`.

The submenu itself receives the command through a menu whose ID matches the submenu ID:

```json
{
  "submenus": [
    {
      "id": "react-webview-vite.webviewMenu",
      "label": "React Webview"
    }
  ],
  "menus": {
    "editor/context": [
      {
        "submenu": "react-webview-vite.webviewMenu"
      }
    ],
    "explorer/context": [
      {
        "submenu": "react-webview-vite.webviewMenu"
      }
    ],
    "react-webview-vite.webviewMenu": [
      {
        "command": "react-webview-vite.openPanel"
      }
    ]
  }
}
```


### Editor vs Explorer context menus

VS Code uses different menu contribution points depending on where the user right-clicks:

```text
Right-click inside an open editor
→ editor/context

Right-click a file in the Explorer sidebar
→ explorer/context
```

If a command should appear in both places, contribute the submenu to both menu IDs.
