# Vite Builds

The project uses Vite for both runtimes, but each runtime needs a different configuration.

## Extension configuration

`vite.extension.config.ts` builds the VS Code extension host.

Important ideas:

- entry: `src/extension/extension.ts`
- target: Node
- output: CommonJS
- external module: `vscode`
- output file: `out/extension.js`

The `vscode` module stays external because VS Code provides it at runtime.

A simplified configuration looks like:

```ts
build: {
  ssr: "src/extension/extension.ts",
  target: "node22",
  outDir: "out",
  rollupOptions: {
    external: ["vscode"],
    output: {
      format: "cjs",
      entryFileNames: "extension.js",
    },
  },
}
```

## Webview UI configuration

`vite.webview.config.ts` builds the browser-side webview UI.

Important ideas:

- entry: `src/webview-ui/index.tsx`
- plugins: React and Tailwind
- output: `out/webview-ui`
- predictable JS name: `webview.js`
- predictable CSS name: `webview.css`
- IIFE output
- inline dynamic imports

A predictable output path keeps the panel host simple. The host-side code lives in `src/extension/webview-panel/webview-panel.ts` and loads assets from `out/webview-ui`:

```ts
const assetRoot = vscode.Uri.joinPath(
  context.extensionUri,
  "out",
  "webview-ui",
);

const scriptUri = webview.asWebviewUri(
  vscode.Uri.joinPath(assetRoot, "webview.js"),
);
```

## Why two configs?

The runtime requirements are different:

| Extension host | Webview UI |
| --- | --- |
| Node.js | Browser |
| CommonJS output | Browser bundle |
| `vscode` external | React bundled |
| No DOM | DOM available |

One build tool is useful. One build configuration would hide important runtime differences.

## TypeScript boundaries

The project also uses two TypeScript configurations.

The root `tsconfig.json` handles extension-host code and excludes the browser-side `src/webview-ui/**` source.

`tsconfig.webview.json` includes browser libraries and JSX:

```json
{
  "lib": ["ES2022", "DOM"],
  "jsx": "react-jsx",
  "moduleResolution": "bundler"
}
```

Run both checks with:

```bash
npm run typecheck
```
