# Getting Started

The repository is designed to run immediately after a normal npm install.

## Requirements

You need:

- Node.js compatible with the version required by Vite
- npm
- VS Code

## Install

From the repository root:

```bash
npm install
```

There is one `package.json`, one lockfile, and one dependency installation.

## Run with F5

Open the repository in VS Code and press:

```text
F5
```

The checked-in launch configuration runs the root build first:

```bash
npm run build
```

That produces:

```text
dist/
├── extension.js
└── webview/
    ├── webview.js
    └── webview.css
```

The Extension Development Host then opens with the repository loaded as an extension.

Open the Command Palette and run:

```text
Open React Webview
```

## Verify message passing

Click:

```text
Send message to VS Code
```

The expected sequence is:

```text
React button
→ webview postMessage
→ extension receives the message
→ VS Code notification appears
→ extension sends a response
→ React updates its status
```

If that works, both sides of the extension are running correctly.

## Development mode

To keep both builds running:

```bash
npm run watch
```

or:

```bash
npm run dev
```

For terminal-driven extension launching:

```bash
npm run build
npm run dev:extension
```

If the VS Code CLI uses a different executable:

```bash
CODE_COMMAND=code-insiders npm run dev:extension
```
