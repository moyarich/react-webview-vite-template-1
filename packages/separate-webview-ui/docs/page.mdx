# React Webview Vite Template

This documentation covers the version of the template where the VS Code extension and React webview live in separate package directories.

The runtime boundary is reflected directly in the repository layout:

```text
Extension host                     Webview
--------------                     -------
root package                       webview-ui package
Node.js                            Browser
src/extension.ts                   webview-ui/src/*
VS Code API available              React + DOM available
        │                              │
        └──────── messages ────────────┘
```

## Start here

From a fresh clone:

```bash
npm install
```

The root `postinstall` also installs dependencies inside `webview-ui/`.

Then open the project in VS Code and press `F5`.

Run **Open React Webview** from the Command Palette.
