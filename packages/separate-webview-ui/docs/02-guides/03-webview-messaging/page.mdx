# Webview Messaging

The example uses one message in each direction.

## React to extension

VS Code exposes `acquireVsCodeApi()` inside the browser webview.

The type declaration lives at:

```text
webview-ui/src/vscode.d.ts
```

```ts
type VSCodeApi = {
  postMessage: (message: unknown) => void;
};

declare function acquireVsCodeApi(): VSCodeApi;
```

The wrapper lives at:

```text
webview-ui/src/api/vscode-api.ts
```

```ts
const vscode = acquireVsCodeApi();

export function postMessage(message: WebviewMessage) {
  vscode.postMessage(message);
}
```

React sends:

```ts
postMessage({
  type: "showMessage",
  message: "Hello from the React webview!",
});
```

## Extension receives the message

The root extension listens with:

```ts
panel.webview.onDidReceiveMessage(async (message) => {
  if (message.type !== "showMessage") {
    return;
  }

  await vscode.window.showInformationMessage(message.message);
});
```

## Extension to React

The extension replies:

```ts
await panel.webview.postMessage({
  type: "messageShown",
  message: "VS Code received the message.",
});
```

React listens with:

```ts
window.addEventListener("message", handleMessage);
```

and updates state when the response arrives.

## Complete flow

```text
React button
→ acquireVsCodeApi().postMessage(...)
→ extension receives message
→ VS Code API
→ panel.webview.postMessage(...)
→ React message event
→ state update
```
