# React Webview Vite Template

This documentation explains the complete implementation behind the minimal VS Code webview example.

The repository intentionally uses one package and two build targets:

```text
VS Code extension host        Webview
Node.js                       Browser
src/extension.ts              src/webview/*
        \                       /
         \                     /
          ---- message bridge ----
```

Both runtimes are built with Vite:

```text
vite.extension.config.ts → dist/extension.js
vite.webview.config.ts   → dist/webview/*
```

## Start here

If you downloaded or cloned the repository:

```bash
npm install
```

Then open the project in VS Code and press `F5`.

Run **Open React Webview** from the Command Palette.
